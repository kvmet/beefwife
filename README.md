# Beefwife

## Common questions

- What is a `Beefwife`?
- Why is it called a `Beefwife`?
- How do I add `Beefwives` to my website?

## Were LLMs or other generative tools used in this project?

Yes, AI (opus5-high, fable5-high, sol5.6-high) was used to assist with programming as well as code reviews and refactors. The project concepts, planning, creative work, taste, and humor are all human-generated. 

This project's stance is that the underlying `Beefwife` simulation/rendering library as well as the `Beefwife Lab` are a "canvas" and "brush" respectively.
You would be hard-pressed to find someone who will dismiss a piece of art solely because the brush used was assembled by a machine.
The "art" of this project is in the overall concept and taste as well as in the designs of the Beefwives themselves, and those aspects are human.
